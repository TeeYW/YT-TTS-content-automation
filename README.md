# Automated YouTube TTS Content Generator and Uploader

A Python automation system that generates long-form YouTube story videos from text and uploads them to YouTube automatically.

## Features

- **Text-to-speech narration:** converts text input into realistic voice narration using Tortoise TTS.
- **Automated video generation:** creates long-form YouTube story videos.
- **Automated uploading:** uses the YouTube Data API to upload videos, including title, description and metadata.
- **User-friendly GUI:** a graphical interface for story input, the generation workflow and upload control.

## How It Works

```
Story text → Tortoise TTS narration → Video generation → YouTube Data API upload
```

## Tech Stack

- Python
- Tortoise TTS
- YouTube Data API
